## 一、项目简介（300 字版，可直接粘申报表）

「字趣·甲骨构字记」是一款以甲骨文为题材的汉字文化互动作品。它不做甲骨文字典的电子化，而是把甲骨文的三条真实性质——**字形由笔画刻成、象形字画的就是那个东西、合体字由构件组合**——分别做成三关玩法：第一关跟着龟宝拆笔画拼字，第二关在殷商王邑图卷上点实物认出对应的象形字，第三关把「构件」当成可击破的部位，与 21 尊由甲骨字形构成的 Boss 交战。

作品使用开源甲骨字形数据集（CC BY 4.0，DOI 10.5281/zenodo.22467946）中的 73 个真字形、37 个构件、153 条图鉴条目，全部字形都是数据集中真实存在的甲骨形；数据集没有整字甲骨形的合体字，一律标注「组合示意」，绝不编造字形。

作品零外部依赖、无框架、无构建，双击 `index.html` 即可离线运行，可直接拷进教室机房。另设「演示模式」，评审可在 30 秒内看到三关的高光状态，退出即还原本机进度。

## 二、创新点（三条）

### 1. 玩法与文字学事实同构，而非给文化套一层皮

多数汉字文化产品把"文化"当皮肤（贴上古风、写几句释义），玩法本身与汉字结构无关。本项目反过来：**机制从文字学事实里长出来**——

| 甲骨文的真实性质 | 对应玩法 |
|---|---|
| 字是**刻**出来的，由可分离的笔画构成 | 第一关：拆笔画、拖回原位拼字 |
| 象形字**画的就是那个实物** | 第二关：在图卷上点实物，认它对应的字 |
| 合体字 = **构件组合** | 第三关：Boss 的可击破部位就是构件，拆掉构件即破防 |

换成任何别的题材，这三条机制都不成立——这是判断"是否真的从文化里长出来"的硬标准。

### 2. 以「不造假」为设计约束的数据纪律

- 73 个字形全部来自带 DOI 的开源数据集，逐笔几何（每笔 path + 包围盒），不是图片；
- 合体字若数据集内无整字甲骨形，界面明确标「组合示意」，**不把构件拼合冒充成整字字形**；
- 王邑地图页明确声明"学习用聚落意象示意，非考古复原"；
- 第三关借用形象一律带「代用」标记，不冒充原生形象。

这条约束牺牲了"看起来更完整"的表象，换来的是**每一条展示都能追溯到出处**。

### 3. 零依赖、可离线的交付形态

8105 行自研代码，无框架、无构建、无 CDN 请求。作品可整体拷入 U 盘，双击即开；这使它具备进入课堂机房、离线展台、乡村学校的现实条件——**不是"能上网才成立"的作品**。

## 四、社会价值与转化路径

### 使用场景

1. **中学语文/历史课堂**：甲骨文与汉字源流单元的随堂互动，一节课可完成第一关；
2. **博物馆/文化馆展台**：离线包 + 演示模式，观众 3 分钟理解"汉字怎么来的"；
3. **研学与亲子**：第二关图卷适合大屏共同探索，家长与孩子一起找实物；
4. **乡村与薄弱学校**：零依赖、可离线，不要求机房带宽。

### 转化设想

- **教学包**：按学段切分字表（现有 153 条图鉴支持筛选），配套教师用讲解稿与课堂任务单；
- **文创衍生**：字形徽记（第三关三档徽记的做法）可延伸为文创图形系统——字卡、书签、印章；
- **开放接口**：字形逐笔数据与「构件—整字」映射可作为开源素材，供其他教育产品复用；
- **赛事/展陈定制**：演示模式可配置成固定展陈流程，无需现场操作。

## 七、答辩预测（10 问，附答法）

1. **"这不就是个识字游戏吗？"**
   → 识字游戏考的是记忆，我们考的是**结构**：字由哪些笔画/构件组成、象形字画的是哪个实物。这三点是文字学事实，不是玩法包装。

2. **"字形数据哪来的？会不会自己画的？"**
   → 全部来自 CC BY 4.0 数据集，带 DOI，页脚署名；数据集里没有的，我们标"组合示意"，不编。

3. **"为什么第三关要设计成打 Boss？"**
   → 因为合体字确实是构件组合的，拆构件=破防，这不是为了战斗而战斗。三档难度也对应三类字：合体字（拆构件）、独体字（拆笔画）、繁复字（混同后只能斩笔画）。

4. **"和同类汉字 App 的差别？"**
   → 三条：机制与文字学同构、数据可追溯不造假、零依赖可离线。同类产品多数只能做到"看图+讲解"。

5. **"学习效果怎么衡量？"**
   → 现有可量化指标：61 个实物点、21 关、153 条图鉴的完成度与答对率，本地存档可导出。后续可做课堂前后测。

6. **"技术上有什么难度？"**
   → 逐笔字形的几何对齐（拖拽吸附）、热点与图卷坐标的统一空间（2624×1472）、手机端小地图视口与 44px 触控热区，都是硬约束下解出来的。

7. **"团队怎么分工？"**
   → 按你实际情况答；建议按"内容与文字学 / 玩法与代码 / 视觉与素材"三段讲。

8. **"后续怎么持续？"**
   → 教学包切分、文创图形延展、字形数据开源复用三条线。

9. **"有没有用到 AI 生成？"**
   → 有，Boss 形象与部分底图用生成式工具产出后做了统一后处理；**已在页脚与素材说明中披露**，不隐瞒。

10. **"如果只保留一关，留哪个？"**
    → 第二关。它把"象形字=画那个东西"讲得最直白，且不依赖前置知识，最适合陌生人 3 分钟理解。
